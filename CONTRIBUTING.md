# Contributing: Beta Testing Hexar

Help us test Hexar by playing and sharing feedback!

## Quick Start

1. Go to https://hexar.fly.dev (or run locally)
2. Play a 15-30 min game (1v1)
3. Send feedback (simple format below)

## What to Report

- **Bugs:** Crashes, visual glitches, unexpected behavior
- **Balance:** Costs feel wrong, techs too weak/strong, unfair matchups
- **Fun:** What felt good? What frustrated you?

## Feedback Format

Just send a simple list:

```
[BUG/BALANCE/FUN] Issue title
- What happened?
- When?
```

**Example:**
```
[BALANCE] Economy L3 costs too much
- Spent 240g at minute 12, didn't feel worth it

[FUN] Liked chaining Vanguard attacks
- Felt rewarding after captures
```
